Device Management - Startanleitung

Starten
1. Öffne den Release-Ordner.
2. Prüfe bei Bedarf config.json.
3. Starte DeviceManagement.exe per Doppelklick.

Wichtig
- Standardmäßig liegt die Datei it_assets.db im gleichen Ordner wie DeviceManagement.exe.
- In dieser Datei werden alle Gerätedaten gespeichert.
- Wenn du das Paket auf einen anderen PC kopierst, kopiere immer den kompletten Ordner.

Gemeinsame Nutzung
- Für mehrere Benutzer kann in config.json ein gemeinsamer Datenbankpfad gesetzt werden, zum Beispiel auf einem Netzlaufwerk.
- Alle Clients sollten dann auf dieselbe zentrale Datenbankdatei zeigen.
- Änderungen anderer Benutzer werden automatisch regelmäßig nachgeladen.

Komfortfunktionen
- Import-Vorschau vor dem Excel-Import
- Export der aktuellen Ansicht
- Backup und Restore
- Duplikat-Check und Hinweise zu fehlenden Hostnamen
- Detailansicht mit Änderungshistorie

Import
- Excel-Dateien können über "Import-Vorschau" geladen werden.
- Für Smartphones werden Rufnummern beim Import ignoriert.
- Nach jedem Import wird automatisch ein Importprotokoll als Textdatei neben der Excel-Datei gespeichert.
